# THREAD-FOLLOWING (v4.1). This replaces CHARACTER-CHANGE.md, which is kept unedited
Trundle (t370u): the Steve example "was mostly about following threads across things". It was not about transformation.
A thread is an event that happens on screen in a show (T: "what happens on screen is what counts"). The thread is then followed:
1. **Event**: it happens in a show clip, e.g. Steve the lizard appears in an episode. It is logged in meta `threads_followed`.
2. **Mention**: a later clip on any channel refers to it in action or a line, e.g. a News anchor speaks ["...a lizard loose downtown..."].
3. **Spin-off promo**: the next slot in the queue carries a promo/ad built on it (AD-Steve-Cold-Blooded-promo, already in prompts_v41/commercials).
Rules: the thread's facts are STATIC once on screen. Only *how* it is expressed is fluid. There is no transform still, and gate V14 is dropped.
